Trip Recommendation Engine

How the Walkthrough Nepal quiz matcher works — a client-side weighted scoring system that ranks trips by user preferences.

System Flow

Scoring Signals

Each trip is scored against 8 signals. A match adds the weight to the trip's total score. No match adds nothing.

Signal Points Weight Bar How It Matches
Duration 10 Trip's parsed day count falls in same bucket as user's pick (short: 5–7d, medium: 8–12d, long: 13–18d, extended: 19+d)
Interests 10 Trip's inferred interests (from title keywords + location mapping) overlap with user's picks
Activity Level 10 Trip's difficulty (EASY→easy, MODERATE→moderate, STRENUOUS→challenging) matches user's pick
Season 10 Trip's bestSeason string contains user's selected season
Budget 5 Trip's price falls in same range as user's pick ($0–1500, $1500–3000, $3000–5000, $5000+)
Traveler Type 5 Always awards points (solo checks groupSize text; couple/family/friends always match)
Featured 3 Trip has isFeatured: true in CMS
Rating 2 Trip's averageRating >= 4.5

Worked Example

A user picks: Couple, Trekking + Photography, 8–12 days, Moderate, Comfort budget ($1,500–3,000), Autumn.

Two trips are scored:

Trip A: Everest Base Camp Trek — 12 days, $2,200, STRENUOUS, rating 4.2, featured
Duration +10 12 days → medium bucket, matches user's medium ✓
Interests +10 "everest"→trekking, title has "trek"→trekking. Overlaps with user's trekking pick ✓
Activity Level +0 STRENUOUS→challenging, user picked moderate ✗
Season +10 "Autumn, Spring" contains "autumn" ✓
Budget +5 $2,200 → comfort range ✓
Traveler +5 couple always matches ✓
Featured +3 isFeatured: true ✓
Rating +0 rating 4.2 < 4.5 ✗
Total: 43 / 55
Trip B: Chitwan Jungle Safari — 4 days, $800, EASY, rating 4.7, not featured
Duration +0 4 days → short bucket, user picked medium ✗
Interests +0 "chitwan"→wildlife, "safari"→wildlife. No overlap with trekking/photography ✗
Activity Level +0 EASY→easy, user picked moderate ✗
Season +10 "Autumn, Winter, Spring" contains "autumn" ✓
Budget +0 $800 → budget range, user picked comfort ✗
Traveler +5 couple always matches ✓
Featured +0 isFeatured: false ✗
Rating +2 rating 4.7 ≥ 4.5 ✓
Total: 17 / 55

Result: Everest Base Camp (43 pts) ranks as a primary pick — it matches on duration, interests, season, budget, and is featured. Chitwan Safari (17 pts) only matches on season and traveler type, so it falls to alternatives or is excluded.

Ranking Logic

  • Every trip with score > 0 is included in results
  • Results are sorted by score descending (highest first)
  • Top 3 are shown as "Primary Recommendations"
  • Next 3 are shown as "More Great Options"
  • Trips with score = 0 are excluded entirely

Scoring is deterministic — same inputs always produce the same ranking. No randomness, no API calls, no server round-trips.

Quiz Flow

  • 6 steps, each a card-selection UI
  • Step 2 (Interests) supports multi-select — user can pick multiple
  • All other steps are single-select
  • Answers are saved to localStorage on every change — refreshing the page resumes where you left off
  • Answers are cleared after results are shown
  • All state is client-side — no server calls during the quiz

How Interests Are Inferred

The engine infers a trip's interests from two sources:

1. Location Mapping

If a trip's locations[] array or title contains a known location keyword, the associated interests are added:
